# 🧳 LugBuddy India

Your on-demand personal shopping helper — available at 200+ malls across India.

## Quick Start
```bash
npm install
cp .env.example .env   # Add your Anthropic API key
npm run dev
```

## Deploy to Railway
1. Push to GitHub
2. railway.app → New Project → Deploy from GitHub
3. Add env var: VITE_ANTHROPIC_API_KEY
4. Settings → Networking → Generate Domain

## Build & Start
- Build: `npm run build`
- Start: `npm run start`
